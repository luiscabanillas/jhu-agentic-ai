# JHU Agentic AI

Course workspace for Johns Hopkins Agentic AI exercises, notebooks, and small projects.

## Overview

This repository is organized primarily by week and contains:

- Jupyter notebooks for lectures, labs, and practice work
- Supporting content for RAG and agentic AI exercises
- A small Week 1 Python app in `ai-inventory`
- A standalone `rock-paper-scissors.py` script

## Repository Structure

- `Pre-Work Session 1/`
  Pre-work notebook material.

- `Week 1 - Python Refresher for Agentic AI/`
  Python refresher notebooks plus the `ai-inventory` mini-project.

- `Week 2 - Introduction to Large Language Models/`
  Prompt engineering and introductory LLM notebooks.

- `Week 3 - Prompt Engineering Techniques & RAG/`
  RAG notebooks, DSPy material, and supporting content.

- `Week 4 - Project 1 - DualLens Analytics/`
  Project notebook and supporting company data.

- `Week 6 - Introduction to Agentic AI Design/`
  Agentic RAG and advanced retrieval notebooks.

- `rock-paper-scissors.py`
  Standalone Python script.

## Getting Started

Most of the work in this repo is notebook-based.

1. Open the repository in VS Code.
2. Select the appropriate Python environment or notebook kernel.
3. Open the notebook for the relevant week.
4. Run cells from top to bottom after installing any required packages in the setup cells.

## Notes

- Some notebooks expect local `config.json` files for API configuration.
- Several notebooks install dependencies inside the notebook itself.
- If a notebook kernel is restarted, rerun the setup cells before continuing.
